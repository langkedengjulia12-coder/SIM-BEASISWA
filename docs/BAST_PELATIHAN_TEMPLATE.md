# Template Pelatihan dan Berita Acara Serah Terima

> Lengkapi bersama UKRI. Jangan menandatangani dokumen sebelum fungsi, akses, dan bukti yang disebutkan diverifikasi.

## Agenda pelatihan pengguna

| Sesi | Materi | Bukti pelaksanaan |
|---|---|---|
| 1 | Login admin/mahasiswa, navigasi, dan pengelolaan akses | Daftar hadir dan hasil uji login |
| 2 | Seleksi pendaftar: verifikasi, keputusan Lolos/Ditolak, dan audit trail | Satu pendaftar uji ditinjau dan perubahan terlihat pada audit trail |
| 3 | Membuat batch dari template CSV dan menjaga kerahasiaan rekening | Batch uji berhasil serta file uji dihapus sesuai prosedur |
| 4 | Impor mutasi, validasi nominal, dan penanganan file yang ditolak | Satu rekonsiliasi uji dan satu file invalid ditolak tanpa perubahan parsial |
| 5 | Ekspor laporan PDF/Excel dan filter audit trail | File PDF dan Excel berhasil dibuka |
| 6 | Backup, pemulihan terisolasi, dan pelaporan insiden | Backup terenkripsi terverifikasi dan hasil uji restore dicatat |
